# Writing ADRs

Adapted from a skill by Zell Gagnon, shared with Matt on 3 June 2026. The guidance also covers keeping the ADR index current, linking replacement decisions, and checking the index during review.

In this skill, `docs/adrs/` refers to the repository being worked on, not this skill's directory. `adrgen` is optional; the skill includes a manual-file fallback.

The skill's source is a private email, not an explicit open-source license grant. Confirm redistribution permission with the author before applying a public license to their text.
